# Laboratory Information Management System (LIMS)

## Overview

This repository contains my final-year Bachelor's project report, titled **"Gestion du système d'information de laboratoire"** (Laboratory Information System Management).

The project focuses on the design and development of a Laboratory Information Management System (LIMS) for an analytical laboratory in the petrochemical refining industry, based on the operational context of SONATRACH's Adrar Refinery.

The objective is to improve the management of laboratory information by replacing scattered Excel files and paper-based processes with a centralized digital system.

## Project Objectives

- Centralize laboratory samples, analyses, and results.
- Improve the organization and traceability of laboratory data.
- Simplify the recording and retrieval of analytical results.
- Generate PDF analysis reports automatically.
- Preserve historical data for long-term reference.
- Reduce repetitive manual work and the risk of data-entry errors.
- Provide controlled access to system functionality through user accounts and permissions.

## Main Features

### Sample Management
Register and organize laboratory samples, including their descriptions, reception dates, priorities, and associated clients.

### Analysis and Results Management
Manage analytical information and results for laboratory workflows involving water and hydrocarbons.

### Report Generation
Generate PDF reports containing analytical results, with filtering options such as date, client, and report type.

### Data Archiving
Centralize laboratory information and improve access to historical records.

### User and Permission Management
Use Django's authentication system to manage user accounts and permissions according to assigned roles.

## Technologies and Methodology

- **Python** — Programming language.
- **Django** — Web application framework.
- **SQLite** — Database management.
- **MERISE** — Information system analysis and design methodology.
- **SQL / Relational Database Modeling** — Data organization and relationships.

## System Design

The report documents the system analysis and design process using MERISE, including:

- Data dictionary and business rules.
- Conceptual Data Model (MCD).
- Conceptual Processing Model (MCT).
- Logical Data Model (MLD).
- Analysis of existing laboratory workflows and information flows.

## Expected Benefits

The proposed system aims to improve laboratory operations by:

- Reducing dependence on paper registers and separate spreadsheets.
- Making analytical information easier to retrieve.
- Improving the consistency and traceability of recorded results.
- Simplifying report production and distribution.
- Supporting more structured laboratory data management.
